## Этап 1. Состояния и правила

Правила ниже уточняют макеты для работы с реальными данными.

| Состояние | Краткий текст | Действие |
| --- | --- | --- |
| Первый запуск | Выберите место | Найти город / По геопозиции |
| Открытие данных | Открываем расписание… | Нет |
| Загрузка дня | Загружаем расписание… | Нет |
| Нет таблицы | Нет расписания на эту дату | Сегодня, если выбран другой день |
| Ошибка загрузки | Не удалось загрузить расписание | Повторить |
| Ошибка хранения | Не удалось сохранить изменения | Повторить |
| Нет офлайн-каталога | Для поиска нужна сеть | Повторить |
| Пустой поиск | Город не найден | Изменить запрос |
| Отказ GPS | Доступ к геопозиции запрещён | Найти город |
| GPS недоступен | Не удалось определить место | Повторить / Найти город |
| Неподдерживаемый профиль | Недоступен в этом браузере | Другой профиль |
| Удаление | Удалить данные? | Отмена / Удалить |
| Неудача удаления | Не удалось удалить данные | Повторить |
| Неудача копирования | Скопируйте выделенную ссылку | Нативное копирование |

Сохранённое расписание остаётся доступным при ошибке обновления. Краткая отметка
об устаревших данных и подробности источника не подменяют его экраном ошибки.
Сведения, необходимые для понимания приблизительных времён, сохраняются.

### Календарь и события

Главная всегда показывает текущий день выбранного места. Выбор даты нативным
календарём открывает полное расписание выбранного дня. Возврат на главную
восстанавливает сегодняшний день. Для другого дня не показываются метка
«сейчас» и живой отсчёт; внизу доступно действие «Сегодня».

Текущим считается последнее наступившее событие намаза/джамаата; следующим —
ближайшее будущее событие того же набора. Дополнительные солнечные отметки
сохраняются в списке. Название джамаата не подменяется началом Фаджра.
Отсчёт менее минуты: «< 1 мин». На самой границе события состояние пересчитывается.
При отсутствии предыдущих/следующих данных не показываются выдуманные значения.

### Совместимость настроек

Никакая миграция оформления не удаляет сохранённые ручные углы, интервалы
и поправки. Они продолжают действовать, но их поля больше не редактируются.
Только при наличии таких значений в параметрах появляется короткая подпись
«Сохранены прежние поправки» и действие «По профилю». Оно удаляет только эти
прежние значения, оставляя выбранные правила Асра и северных широт.

Выбор другого профиля загружает его стандартные параметры. Если есть прежние
поправки, на странице профилей заранее показано: «Выбор профиля заменит прежние
поправки». Простое открытие параметров, возврат или переключение Авто/таблица/
ручной сохраняет черновик. Для новых пользователей дополнительных пояснений нет.

Единственная тема — утверждённый тёмный монохром. Сохранённая старая настройка
оформления не меняет визуальный результат; её чтение сохраняется для совместимости.

### Навигация и адаптация

Экраны открываются внутри общей оболочки. «Назад» и браузерный возврат возвращают
к предыдущему экрану, «Отмена» поиска — к локации. Тап по городу завершает весь
выбор и возвращает на главную. Фокус возвращается к вызвавшей кнопке.
При первом запуске возврат из локации ведёт к экрану выбора места без ложных данных.

На небольших высотах прокручивается содержимое; верхние и нижние действия
остаются доступными. Системный календарь и клавиатура не заменяются нарисованными.
На широком экране сохраняется центральная компактная композиция без рамки телефона.

## Ход работ

- Этап 1: правила состояний, календаря и совместимости зафиксированы.
- Этап 2: добавлены Screen, общие стили и локальный шрифт; верхнеуровневые
  переходы App переведены на типизированную историю с возвратом фокуса.
  Проверки навигации, оболочки и интеграции App проходят. Старые компоненты
  содержимого будут последовательно заменены на этапах 3–6; старый CSS удаляется на этапе 7.
- Этап 3: главная и список разделены; календарь открывает выбранный день,
  возврат восстанавливает сегодняшнюю сводку. Текущее событие обновляется на
  границе времени. Проверены 43 сценария событий/сводки/календаря, TypeScript
  и отображение в Chromium при 320/390 px: поля 16 px, без обрезки и ошибок.
- Этап 4: локация и поиск вынесены в отдельные экраны; выбор сразу возвращает
  на главную. Миграция IndexedDB v10 добавляет максимум три недавних города,
  сохраняя прежние данные; GPS в историю не попадает. Проверены 59 сценариев
  хранения, поиска, геопозиции и навигации, а также интеграция выбора в App.
  В Chromium при 320/390 px поля и строки имеют отступы 16 px, поиск получает фокус.
- Этап 5: меню настроек, источник, выбор способа и профиля, параметры переведены
  на отдельные экраны. Настройки сохраняются немедленно через общую очередь;
  прежние числовые поправки удаляются только явным действием. Сведения об источнике
  и описание расчёта открываются с последовательным возвратом. Проверены 12 сценариев
  настроек/очереди и 3 интеграционных сценария App, TypeScript, ESLint и сборка.
  Три режима источника и параметры проверены в Chromium при 320/390 px.
- Этапы 6–8: предстоят.
