## Реальные сетевые сценарии

[privacy.spec](../tests/privacy.spec.ts) собирает request events всего browser context,
включая Worker и service worker: первый/повторный запуск, поиск Стамбула,
выбор города, изменение настроек, копирование ссылки, фоновая проверка таблицы,
reset/reload. Отдельно проверены GPS и запуск с уже выданным разрешением.
Наблюдались только GET публичных файлов текущего origin, без request body;
служебный query precache — только `__WB_REVISION__`. Координаты, ID выбранного
города, текст поиска и настройки к URL/body не добавлялись; cookies отсутствовали.
Проверка изменённой таблицы использует контролируемый manifest/JSON с валидным hash.
Полный перечень потоков и локальных записей — в [app-data.md](app-data.md).

При первой установке загружен индекс, 0 городских пакетов. Поиск «Киров» получил
15 пакетов / 657 590 байт исходных JSON, затем работал офлайн. При неизменившемся
manifest повторный запуск не загружает JSON таблицы. Sharing читает статический
QR и копирует текущий URL, без добавления места/настроек. Reset не возобновляет
фоновую загрузку таблиц или GPS до нового выбора. Direct `/salah-pwa/privacy/`
доступен online и offline после установки оболочки, без исполняемого JavaScript.

Публичный канал связи подтверждён read-only запросами: API GitHub возвращает
публичный `halsab/salah-pwa`, `has_issues: true`, `archived: false`; страница
[Issues](https://github.com/halsab/salah-pwa/issues) — HTTP 200 с кнопкой создания issue.
Никакие обращения от имени пользователя не отправлялись. Первичные страницы
[GitHub Pages](https://docs.github.com/en/pages/getting-started-with-github-pages/what-is-github-pages#data-collection),
[GeoNames](https://download.geonames.org/export/dump/readme.txt) и
[geoBoundaries](https://www.geoboundaries.org/api/current/gbOpen/RUS/ADM1/)
сверены; текущие CSV/XLSX ДУМ РТ также ответили HTTP 200.

## Исправления и границы результата

Старая политика содержала технические детали вместо кратких ответов; исправлены
её содержание, контакт, атрибуция и позиционирование. Документация больше не
называет reset и SourceInfo будущими и не описывает солнечные markers как цель
главного таймера. Manifest identity, start_url, scope и пути установки сохранены.

Первый полный прогон имел 413 зелёных тестов, но **не проходил coverage** для
части domain/storage/manifest/scripts. Добавлены проверки повреждённых параметров,
отказа WebCrypto/декодирования, генерации coverage, конкурирующего upgrade,
инвалидирования сохранения и rollback/retry reset. Последний тест сначала
воспроизвёл необработанный AbortError после синхронного сбоя второго clear.
Очистка теперь ждёт каждый запрос внутри одной транзакции; повторный тест и
production reset проходят без unhandled rejection. При разработке нового
browser-теста исправлен его селектор `alert` на фактический `status`; поведение
приложения ради теста не менялось. Визуальная проверка обнаружила ссылки политики
с областью нажатия меньше 44 px: добавлена регрессионная проверка и исправлен
CSS только этой страницы, без изменения её бумажного оформления. Для нижней ссылки и даты редакции
в тёмной теме тест воспроизвёл контраст 1,26:1; цвет исправлен, тест требует
не менее 4,5:1 в обеих темах.

Первичные ограничения окружения: sandbox запрещал DNS и создание локальных
сокетов (preview/tsx). После разрешённого запуска этих проверок вне sandbox
они выполнены; это не оставшаяся сетевая блокировка. При `npm ci` были
предупреждения npm о deprecated glob и install scripts; установка, сборка и
`security:audit` завершились успешно. Политики безопасности не ослаблялись.

[CI](../.github/workflows/ci.yml) читает `.nvmrc`, выполняет `npm ci` и все
проверки, передаёт `dist` в Pages только при `inputs.deploy`.
[Релиз](../.github/workflows/release.yml) вызывается вручную из `main`, фиксирует
commit и включает deploy после проверок. Workflow обновления данных только
создаёт PR. Workflow-файлы не требовали изменения; удалённый CI, релиз и deploy
**не запускались**. Установка проверена как manifest + активация SW и offline
поведение, без физической установки на устройство.

Полное закрытие всех 20 пунктов не заявляется: поставщик должен уточнить
календарную принадлежность позднего сухура (№8). Граница Татарстана проверена
на закреплённой геометрии и контрольных точках; её актуальность на местности,
мировая координатная timezone и физические мобильные устройства не покрыты этой проверкой.
