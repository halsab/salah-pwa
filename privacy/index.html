Salah · политика проекта

Конфиденциальность

Salah показывает времена намаза: готовое расписание ДУМ Республики Татарстан и автономный расчёт для других мест.

Кто отвечает за проект

Владелец проекта: GitHub-пользователь halsab.

Страница проекта и исходный код предназначена для просмотра проекта. Она не является каналом для конфиденциальных обращений; отдельные имя, email или контактные данные не заявлены.

Salah не является официальным приложением ДУМ РТ (Духовного управления мусульман Республики Татарстан).

Что остаётся в браузере

У приложения нет собственного сервера, аналитики и cookies. Координаты, настройки и расписания сохраняются только в браузере: пользовательский выбор и проверенный набор расписаний — в IndexedDB, а оболочка приложения, небольшие служебные файлы и каталог городов после первого использования — в Cache Storage.

Эти данные можно удалить через настройки данных сайта в браузере. Отдельной кнопки сброса внутри Salah нет.

Статический хостинг

Статические файлы размещены на GitHub Pages. При загрузке страницы GitHub может получить IP-адрес, сведения о запросе и устройстве в соответствии с политикой конфиденциальности GitHub.

Геопозиция и Nominatim

Браузер передаёт позицию приложению только после разрешения. Salah не ведёт непрерывное отслеживание местоположения.

Один reverse-запрос к Nominatim выполняется при автоматическом определении местоположения — в том числе на старте при ранее разрешённой геопозиции — и после явного нажатия «Уточнить название онлайн». Он нужен для названия места и проверки кода региона.

Передаются только широта и долгота, округлённые до трёх знаков (0,001°). Точность браузера и timestamp не передаются.

format=jsonv2 zoom=10 addressdetails=1 accept-language=ru

Публичный сервис Nominatim получает IP-адрес и может журналировать технические данные запроса согласно политике OSMF. Возвращённое название сохраняется локально, а код региона используется для выбора между готовым и расчётным расписанием.

Источники и преобразования данных

Расписание ДУМ РТ

Источник — ДУМ РТ. Опубликованные таблицы разбираются, проверяются на полноту и дубли, объединяются в JSON и сопровождаются manifest и SHA-256 для проверки перед сохранением.

Отдельная лицензия таблиц ДУМ РТ не указана, поэтому проект её не утверждает.

Каталог GeoNames

Используются наборы cities5000.zip и alternateNamesV2.zip по лицензии CC BY 4.0.

В каталог входят населённые пункты с населением от 5 000 человек. Координаты округляются до четырёх знаков, выбираются действующие русские названия с предпочтением preferred, строится нормализованный поисковый индекс, а данные сохраняются как компактные записи.

OpenStreetMap и Nominatim

Геокодирование использует данные OpenStreetMap / Nominatim, доступные по лицензии ODbL. Возвращённое название сохраняется локально, код региона используется для подтверждения территории.
