Salah · политика проекта

Конфиденциальность

Salah показывает времена намаза: готовое расписание ДУМ Республики Татарстан и автономный расчёт для других мест.

Кто отвечает за проект

Владелец проекта: GitHub-пользователь halsab.

Страница проекта и исходный код предназначена для просмотра проекта. Она не является каналом для конфиденциальных обращений; отдельные имя, email или контактные данные не заявлены.

Salah не является официальным приложением ДУМ РТ (Духовного управления мусульман Республики Татарстан).

Что остаётся в браузере

У приложения нет собственного сервера, аналитики и cookies. Координаты, настройки и расписания сохраняются только в браузере: пользовательский выбор и проверенный набор расписаний — в IndexedDB, а оболочка приложения, небольшие служебные файлы и небольшой обзор городов — в Cache Storage. Загруженные пакеты городов сохраняются в IndexedDB.

Эти данные можно удалить через настройки данных сайта в браузере. Отдельной кнопки сброса внутри Salah нет.

Статический хостинг

Статические файлы размещены на GitHub Pages. При загрузке страницы GitHub может получить IP-адрес, сведения о запросе и устройстве в соответствии с политикой конфиденциальности GitHub.

Локальная геопозиция

Браузер передаёт позицию приложению только после разрешения. Salah не ведёт непрерывное отслеживание местоположения. Координаты не отправляются в Nominatim или другие геокодеры, в том числе при запуске с ранее разрешённым GPS.

Место, точность GPS, время получения, часовой пояс и его ручная настройка сохраняются локально. Город-ориентир ищется в уже сохранённых пакетах GeoNames. Приложение запрашивает с собственного хостинга только статические файлы без координат в URL или теле запроса. Собственная служба определения позиции браузера или ОС может использовать сеть в соответствии с настройками устройства.

Территория Татарстана проверяется по локальной границе. На границе и при недостаточной точности GPS покрытие не считается подтверждённым. В остальных местах без локальных данных о timezone применяется зона устройства с явным пояснением и возможностью ручной настройки. Сохранённый ручной выбор города не запускает GPS; автоматическое место обновляется при разрешённом GPS, если измерению не меньше 30 минут или его время некорректно.

Источники и преобразования данных

Расписание ДУМ РТ

Источник — ДУМ РТ. Опубликованные таблицы разбираются, проверяются на полноту и дубли, объединяются в JSON и сопровождаются manifest и SHA-256 для проверки перед сохранением.

Отдельная лицензия таблиц ДУМ РТ не указана, поэтому проект её не утверждает.

Каталог GeoNames

Используются наборы cities5000.zip, alternateNamesV2.zip и admin1CodesASCII.txt по лицензии CC BY 4.0.

В каталог входят населённые пункты с населением от 5 000 человек. Координаты округляются до четырёх знаков, выбираются действующие русские названия с предпочтением preferred, строится нормализованный поисковый индекс, а данные сохраняются как компактные записи.

Локальные границы OpenStreetMap

Граница Татарстана — данные OpenStreetMap через geoBoundaries, снимок 2017 года, фиксированная версия 9469f09, лицензия ODbL. Извлечён только Татарстан, геометрия упрощена с допуском 100 м и округлена до пяти знаков. Полоса неопределённости — 2 км плюс точность GPS; это запас приложения, а не гарантия точности источника. Геопакет включён в offline-набор. Названия, ранее полученные из Nominatim, сохраняются при миграции без сетевого запроса.
