# Salah

Offline-first PWA с официальными временами намаза ДУМ Республики Татарстан и автономным расчётом для других местностей. Приложение определяет координаты по GPS, поддерживает офлайн-выбор городов мира и учитывает северные широты.

Salah не является официальным приложением ДУМ РТ. Политика обработки локальных данных и внешних запросов опубликована на статической странице [«Конфиденциальность»](https://halsab.github.io/salah-pwa/privacy/); сведения об источниках и лицензиях собраны в [THIRD_PARTY_NOTICES.md](THIRD_PARTY_NOTICES.md).

## Данные

Источник — [официальный раздел «Время намаза» ДУМ РТ](https://dumrt.ru/ru/help-info/prayertime/). Времена не пересчитываются в браузере: в приложение импортируются опубликованные ДУМ РТ таблицы для всех 44 населённых пунктов.

`npm run data:update` загружает источники, проверяет формат, отсутствие пропусков и дублей, а затем сохраняет текущий год и, когда он полностью опубликован для всех пунктов, следующий. Набор сопровождается небольшим manifest с версией и SHA-256: приложение проверяет загруженные байты до разбора и атомарно сохраняет подтверждённый набор в IndexedDB. Это позволяет принять обновление заранее без разрыва расписания на Новый год. Workflow `Обновление расписания ДУМ РТ` выполняет проверку еженедельно и при изменениях создаёт pull request. В настройках репозитория необходимо разрешить GitHub Actions создавать pull request.

Офлайн-справочник содержит города GeoNames с населением от 5 000 человек и распространяется по лицензии [CC BY 4.0](https://creativecommons.org/licenses/by/4.0/). Он обновляется командой `npm run data:update:cities`; в выборе показываются пять крупнейших городов каждой страны, остальные доступны через поиск.

## Локальный запуск

```bash
npm ci
npm run dev
```

Полная проверка перед релизом:

```bash
npm test
npm run typecheck
npm run build
npx playwright install chromium
npm run smoke:offline
npm run smoke:sw-update
```

Offline smoke-test запускает production preview, дожидается активации service worker, отключает сеть и проверяет повторное открытие расписания из IndexedDB. SW update smoke-test временно изменяет собранный service worker, проверяет единственную безопасную перезагрузку и восстанавливает исходные байты.

## Архитектура

- React 19 и строгий TypeScript без роутера и глобального state manager;
- чистые функции для даты, геолокации и следующего намаза;
- небольшой типизированный слой IndexedDB на `idb` с явной миграцией схемы и каноническим проверенным набором расписаний;
- Workbox precache для оболочки приложения и небольшого manifest; официальный набор расписаний не сохраняется в Cache Storage;
- Vitest, React Testing Library, `user-event`, jsdom, fake-indexeddb и Playwright.

Координаты используются на устройстве для расчёта. При автоматическом определении местоположения, включая запуск с ранее выданным разрешением, и после явного нажатия «Уточнить название онлайн» широта и долгота округляются до трёх знаков и передаются OpenStreetMap Nominatim для получения названия и кода региона. Точность браузера и timestamp не передаются, непрерывного отслеживания нет; полученное название кешируется локально.

## Публикация

Push в `main` и pull request запускают проверки без публикации. Production-релиз запускается вручную через workflow `Создать релиз` в GitHub Actions из ветки `main`. Workflow находит последний тег текущего года, увеличивает номер (`v26.4` → `v26.5`), передаёт его в Vite, выполняет все проверки, публикует `dist` в GitHub Pages и создаёт одноимённые Git-тег и GitHub Release. В новом году нумерация автоматически начинается с `1`.

Одновременно может выполняться только один релиз. В настройках Pages источником должен быть выбран **GitHub Actions**.
