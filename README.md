# Salah

Offline-first PWA с официальными временами намаза ДУМ Республики Татарстан. Приложение показывает расписание на выбранную дату для всех доступных населённых пунктов, локально определяет ближайший пункт и считает время до следующего намаза.

## Данные

Источник — [официальный раздел «Время намаза» ДУМ РТ](https://dumrt.ru/ru/help-info/prayertime/). Времена не пересчитываются в браузере: в приложение импортируются опубликованные ДУМ РТ таблицы для всех 44 населённых пунктов.

`npm run data:update` загружает источники, проверяет формат, отсутствие пропусков и дублей, а затем сохраняет текущий год и, когда он полностью опубликован для всех пунктов, следующий. Это позволяет принять обновление заранее без разрыва расписания на Новый год. Workflow `Обновление расписания ДУМ РТ` выполняет проверку еженедельно и при изменениях создаёт pull request. В настройках репозитория необходимо разрешить GitHub Actions создавать pull request.

## Локальный запуск

```bash
npm ci
npm run dev
```

Полная проверка перед релизом:

```bash
npm test
npm run typecheck
npm run build
npx playwright install chromium
npm run smoke:offline
```

Offline smoke-test запускает production preview, дожидается активации service worker, отключает сеть и проверяет повторное открытие расписания.

## Архитектура

- React 19 и строгий TypeScript без роутера и глобального state manager;
- чистые функции для даты, геолокации и следующего намаза;
- небольшой типизированный слой IndexedDB на `idb` с явной миграцией схемы;
- Workbox precache для приложения и официального набора данных;
- Vitest, React Testing Library, `user-event`, jsdom, fake-indexeddb и Playwright.

Координаты геолокации обрабатываются только на устройстве и никуда не отправляются.

## Публикация

После push в `main` GitHub Actions выполняет воспроизводимую установку, тесты, typecheck, production build и offline smoke-test, затем публикует `dist` в GitHub Pages. В настройках Pages источником должен быть выбран **GitHub Actions**.
